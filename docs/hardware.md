# 自宅サーバーの可否判断

## 実機スペック

| 項目 | 実機 |
| --- | --- |
| CPU | Core i5-3570 (Ivy Bridge, 4C/4T, 3.4–3.8GHz, AVX) |
| GPU | Radeon HD 6450 |
| RAM | DDR3 8GB |
| ストレージ | SATA SSD 128GB + HDD 250GB |

## 要件との突き合わせ

| 要件 | 実機 | 判定 |
| --- | --- | --- |
| Node.js >= 22 (`package.json` の `engines`) | x64 / AVX 対応 CPU | OK |
| ネイティブモジュール | `@crosscopy/clipboard` の x64-gnu バイナリのみ。SSE4.2 以降で動作 | OK |
| メモリ | アイドル時 300–500MB、1 ターン実行時でも 1–2GB 程度 | OK (8GB で余裕) |
| GPU | ローカル推論をしないため不要 | 無関係 |
| ストレージ | OS + Node + cmd で 15GB 程度。リポジトリは SSD 推奨 | OK |
| 常時ネットワーク | クラウド推論が前提なので必須 | **実質的な唯一の要件** |

**結論: 問題なく動く。** ボトルネックは CPU でもメモリでもなく回線。

## 運用上の注意

- **メモリ 8GB の使い方。** `npm i -g command-code` のインストール時と、大きいリポジトリでの並列実行は控えめにする。bot 側で同時実行数を 1〜2 に制限する。
- **有線 LAN 推奨。** Wi-Fi でも動くが、ストリーミング出力が途切れやすい。
- **HDD は作業用。** SSD に OS と Node、HDD にログや大きいリポジトリを置く。SSD 128GB は余裕が少ないのでログローテーションを入れる。
- **24 時間稼働。** 消費電力・発熱・騒音はこのクラスなら問題にならない。UPS は任意だが、停電でセッションが切れる点は許容する。
- **GPU は完全に遊ぶ。** 将来的にローカルモデルを試したくなったら別マシンの話になる。
